# V1 产品范围

## 1. 产品定义

Java Code Audit Platform V1 是一个个人使用的 Java 代码审计工具。用户通过 REST API 上传一个源码 ZIP，或提交一个 SVN 地址；系统执行确定性的开源扫描器和受控 CodeQL 分析，统一生成可下载报告。

V1 的最近邻是“在 CI 中串联多个扫描脚本”。决定性差异是平台提供统一任务状态、并发控制、Finding 模型、跨引擎去重、覆盖信息、文件保留和单一报告，而不是只拼接若干命令输出。

## 2. 目标用户与环境

- 使用者：项目维护者本人；
- 源码：自己有权审计且满足各扫描器许可条件的可信项目；
- 项目类型：Java 17 Maven 单模块或标准多模块 Reactor；
- 开发与首要验收：macOS ARM64；
- 发布与自动验收：Linux x86_64、Ubuntu 22.04、glibc 2.34+；
- 网络：允许访问 SVN、Maven 仓库、工具官方源和漏洞数据库；
- 部署：一个 Spring Boot 可执行 JAR，加配置、工具和数据目录。

## 3. V1 包含

### 3.1 输入

- ZIP 上传；
- SVN `HEAD` 当前快照或指定单一 revision；
- SVN 匿名访问或临时用户名/密码；
- 安全解压、容量限制、Maven 根识别；
- 每个任务仅接受一个 Maven Reactor 根；
- Maven Profile 和受控 `-D` 属性。

### 3.2 扫描档位

| 档位 | 用途 | 核心行为 |
| --- | --- | --- |
| QUICK | 尽快获得源码层反馈 | 不依赖 Maven 构建成功，执行源码、规范、密钥、重复和仓库配置扫描 |
| STANDARD | 默认综合审计 | Quick + `mvn -DskipTests package` + 字节码、依赖、SBOM 和构建治理 |
| DEEP | 深度安全分析 | Standard + CodeQL 跨文件/跨过程查询 |

### 3.3 执行与并发

- Java `ProcessBuilder` 本地启动扫描器；
- 参数数组传递，不通过 Shell 拼接；
- 有界任务队列、任务级并发、引擎级并发、资源权重；
- Maven、Dependency-Check、CodeQL 独立并发限制；
- 超时、取消、进程树终止、日志限长、磁盘阈值；
- 文件持久化和单实例文件锁；
- 服务重启时恢复排队/终态任务，运行中任务标记为 `INTERRUPTED`。

### 3.4 输出

- HTML 中文主报告；
- JSON 机器可读报告；
- SARIF 标准交换报告；
- CycloneDX SBOM；
- 原始扫描器报告和脱敏日志；
- 唯一问题数、原始命中数、P0-P3、12类问题和引擎覆盖；
- 文件、行号、有限代码片段、Source/Sink 路径、修复建议和原始证据；
- 路径排除与规则抑制。

## 4. V1 不包含

- 独立 Web 管理页面；
- API Token、用户、角色和权限体系；
- PostgreSQL、MySQL、Redis、MQ；
- Docker、Podman、Kubernetes、微虚拟机或远程 Runner；
- 任意公网不可信代码的安全沙箱；
- Java 8/11/21 项目构建矩阵；
- Gradle、Ant 或非 Java 项目；
- 一个任务扫描多个独立 Maven 根；
- SVN 完整历史和历史密钥扫描；
- Maven Wrapper 自动执行；
- 完全离线 Maven 仓库和漏洞库介质；
- 历史基线、增量扫描和跨任务趋势；
- Error Prone、NullAway；
- AI 解释、误报判定、自动修改代码；
- 启动目标 Web 应用后的 DAST、ZAP 或渗透测试；
- 业务越权、金额流程、租户隔离等业务语义证明；
- 实际 Linux 服务器人工验收作为 V1 阻塞条件。

## 5. 关键边界

### 5.1 不提供安全隔离

即使设置 `-DskipTests`，Maven 插件和构建生命周期仍能执行项目代码。V1 在宿主机直接执行 Maven，因此只允许扫描可信来源。ZIP 防护用于保护文件系统和稳定性，不能把恶意项目变成安全项目。

### 5.2 静态结果不是漏洞证明

扫描器会有误报和漏报。依赖存在 CVE 不代表当前程序一定可达；未发现问题也不代表不存在业务逻辑或运行时漏洞。报告必须展示扫描覆盖、工具失败、数据库时间和证据来源。

### 5.3 CodeQL 受单独条款约束

CodeQL 查询库和 CLI 许可不同。CLI 不进入公共仓库或公共介质；仅对满足 GitHub CodeQL 当前条款或另有合法授权的目标启用。平台开源不自动意味着所有上传项目都可由 CodeQL 扫描。

## 6. 成功定义

用户可以在 Mac 上用一个启动命令启动服务，上传一个合法 Java 17 Maven 项目，选择任一档位并最终下载统一报告；Linux 发布工作流可在 Ubuntu 22.04 x86_64 组装同一版本并完成约定的自动验收。详细完成条件见[验收标准](acceptance-criteria.md)。
